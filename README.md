# Filebox

管理者がファイルを登録し、受け取り用のURLとパスワードを発行するPHP製のファイル受け渡しツールです。登録済みファイルの削除と、ダウンロード回数の確認にも対応します。

## 配置と起動

PHP 8系、PDO SQLite拡張、Apache 2.4の `.htaccess` 設定を有効にした環境が必要です。TLS証明書を設定してHTTPSでアクセスできるようにしてください。同梱の `.htaccess` はHTTPからHTTPSへ転送する設定です。公開するフォルダを `FTP/` に設定し、書き換え機能とアクセス拒否設定を許可してください。`FTP/data/` と `FTP/uploads/` はPHPから書き込める必要があります。

Webサーバーの環境変数で、次の2項目を設定します。

| 名前 | 指定する内容 |
| --- | --- |
| `FILEBOX_ADMIN_PASSWORD` | 自分で決めた12文字以上の管理者パスワード |
| `FILEBOX_BASE_URL` | 配置先のURL。末尾の `/` は不要 |

`config.example.txt` は設定名を示す見本です。アプリはこのファイルを自動では読みません。サーバーの管理画面やApache設定で指定してください。設定がない状態では503エラーで停止します。

PHP側の `upload_max_filesize` と `post_max_size` も必要な容量に設定します。アプリの上限設定は200MBです。Webサーバー側の容量制限がこれより小さいと、その制限が優先されます。

設定後、配置先のURLを開き、管理者パスワードでログインします。ファイルを登録すると受け取り用のURLとパスワードが表示されます。受け取り側はURLを開いてパスワードを入力します。

## 現在の状態と制限

管理画面、ファイル登録・削除、受け取り画面、ダウンロード数の記録を実装済みです。元の運用設定と保存ファイルを除いたソース公開版であり、このコピーのサーバー動作確認は行っていません。

- PHP内蔵の簡易サーバーは `.htaccess` を適用しません。そのまま公開すると保存データへアクセスされるため、この手順の対象はApacheです。
- `data/` と `uploads/` の直接アクセス拒否が有効な環境で使用してください。
- 操作要求の偽造を防ぐ対策や、ログイン試行回数の制限などは未整備です。インターネットでの本番公開前には別途整備が必要です。
- 登録ファイルの自動期限切れ機能はありません。管理画面から削除します。
